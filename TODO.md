- Loop-agnostic data + ledger design (expanded vision; build trading first, earn each loop by finishing the last). Project ambition has grown from "cargo trading" to "a personal companion for all ECONOMIC game loops" — trading, mining, salvage, refining — unified by the cargo ledger and a shared aUEC/hr comparison. DESIGN DECISION to honor when the ledger is built: model a money loop generically as { source_activity, items_acquired, items_sold, time_spent, profit }, where source_activity = "trade" today and "mining"/"salvage"/"refining" later. - Travel-time model: load/unload asymmetry + per-terminal access friction (ESCALATION-GATED, travel-time constants). Findings: (a) loading is concurrent with walk-back to ASOP (timer overlaps travel), but blocks ship retrieval from ASOP until done — effective load delay = max(0, load_time − walk_time); (b) unloading is serial: terminal-travel happens BEFORE unload can start, so unload cost = terminal_travel + unload_time (fully additive). - Live loop re-routing with commitment-state safety (post-v1, depends on multi-leg planner + cargo tracker). In a multi-leg loop, feed updates (price move, qty crater, terminal OUT OF STOCK) could re-path remaining legs to keep the loop optimal — staleness compounds across legs, so a loop that re-plans as you fly is more honest than one computed once. SAFETY RULE (critical, easy to get wrong): re-routing must respect commitment state. Updates may freely re-plan FUTURE / uncommitted legs, but must NEVER silently alter the leg the player is currently committed to. States: planning (anything changes) → en route to buy / no cargo (can divert, warn don't force) → CARGO LOADED en route to sell (LOCKED — the cargo dictates the destination; physics, not preference) → at terminal transacting (LOCKED). Committed-leg changes are ADVISORY only ("heads up — your planned sell at Y dropped; alternatives on arrival: Z, W"), surfaced at natural decision points (arrival, choosing next leg), never pushed mid-transit. Requires loop progress-state tracking, which the cargo tracker provides.
